# Contracts

This folder contains machine-readable contract sketches for AKDB integrations.

| File | Purpose |
| --- | --- |
| `API_CONTRACT_OPENAPI.yaml` | FastAPI/OpenAPI contract sketch for local HTTP clients. |
| `MCP_TOOLS_MANIFEST.json` | MCP tool manifest exported by AKDB. |

Update these files when a public API, CLI-to-API payload shape, or MCP tool contract changes.
